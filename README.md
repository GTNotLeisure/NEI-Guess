# NEI Guess

**让 NEI 搜索框变成浏览器地址栏。**

点击 NEI 搜索框，即可查看收藏、搜索历史、任务需求、常用搜索词等候选内容；点击任意条目即可直接搜索。也支持拼音搜索、搜索词补全、聊天物品链接和自定义推荐词库。

这是 [JEI Guess](https://github.com/) 的 Minecraft 1.7.10 NEI 移植版，原作者 Maixr，遵循 MIT 许可协议，详见 `LICENSE-JEIGuess.txt`。

> 本项目与 NEI、JEI 官方及其作者无隶属关系。

## 功能介绍

### 智能搜索建议

打开搜索框后，NEI Guess 会根据你的使用习惯提供搜索建议。默认首页显示 8 条候选内容，后续页面按来源分类浏览。

| 来源 | 默认数量 | 内容 |
|---|---:|---|
| 收藏 | 2 | 手动收藏的搜索词，始终优先显示 |
| 最近搜索 | 3 | 最近搜索过的词，自动合并 NEI 自带搜索历史 |
| 任务需求 | 3 | 最近查看的未完成 BetterQuesting 任务所需物品 |
| 常用搜索 | 1 | 搜索次数最多的词 |
| 推荐 | 1 | 从推荐词库中随机选取 |
| 上次选择 | — | 再次输入相同搜索词时，优先显示上次点开的物品 |
| 聊天记录 | 0 | 从聊天消息中提取的物品，单独提供完整列表 |

鼠标滚轮或键盘可以翻页。首页之后，每个来源都有独立页面，条目较多时会自动继续分页。其他模组也可以注册自己的候选来源。

所有来源的显示数量、启用状态等都可以自行配置。

### 中文搜索与自动转换

NEI 原生的模组搜索（`@`）使用模组显示名称，而不是中文翻译。因此，直接搜索中文模组名通常无法得到结果。

NEI Guess 会自动识别并转换常见搜索词：

- **模组名称**：输入中文模组名，自动转换为 NEI 支持的 `@"Mod Name"` 搜索格式。通过创造模式物品栏标签页和物品注册信息建立映射，不依赖特定整合包或语言文件；同时支持 modid，并内置取自 [GTNH-Translations](https://github.com/GTNewHorizons/GTNH-Translations) 的创造模式标签页中文名，英文客户端也能用中文搜模组。
- **矿物词典**：1.7.10 没有现代版本的物品标签系统，因此使用矿物词典（Ore Dictionary）提供类似功能。输入物品名称可以找到相关矿辞，例如搜索「铜锭」可以匹配 `ingotCopper`；输入「锭」「小撮粉」「致密板」等格雷科技前缀译名（同样取自 GTNH-Translations）可以直接搜对应矿辞前缀。
- **矿辞显示名称**：优先使用该矿辞第一个物品的显示名称，不依赖额外的人工翻译。
- **搜索纠错**：如果原始搜索词无法在 NEI 中找到结果，会尝试模组名称、矿辞、modid 和物品名称匹配。原始搜索已经有效时，不会擅自修改搜索词。

同时兼容 NEI 的普通、通配符、正则表达式和扩展匹配模式，以及自定义搜索前缀。

### 拼音搜索

安装 NotEnoughCharacters 后，可以使用拼音或首字母搜索：

- `yyny` → 应用能源2
- 支持物品名称、模组名称和矿辞名称。
- `@`、`$` 等搜索语法提示也支持拼音匹配。
- 沿用 NotEnoughCharacters 的模糊音设置。

### 聊天物品链接

聊天消息中的物品名称会自动加上下划线，变成可交互链接。

支持识别：
- 物品显示名称
- `modid:name`
- `$矿辞`
- 模组名称

点击链接可以直接打开物品合成表，Ctrl + 点击查看用途，Alt + 点击复制物品 ID。Shift + 点击保留 Minecraft 原版的插入文字行为。

悬停时会显示物品提示。矿辞和模组名称链接则会打开物品栏并自动填入对应的 NEI 搜索词。

链接识别会优先匹配较长的名称，英文名称按完整单词匹配，并且不会覆盖其他模组已经注册的点击事件。所有操作均在客户端执行，不会向服务器发送命令。

### 搜索辅助

除此之外，还提供一些方便日常使用的小功能：

- **灰色文字补全**：根据当前输入提供搜索词补全，按 Tab 接受。
- **拼写纠错**：例如输入「钻石搞」，会提示你是否想搜索「钻石镐」。
- **语法提示**：输入 `@` 或 `$` 时，显示对应的模组或矿辞搜索建议。
- **任务浏览跟踪**：记录最近查看的任务，方便查找任务所需物品。
- **搜索历史导出**：可以将历史记录导出为 CSV 文件，方便整理和分析。

## 操作方式

| 操作 | 功能 |
|---|---|
| 左键 / Enter | 搜索选中的候选项 |
| 右键 | 收藏或取消收藏 |
| Shift + 右键 | 从历史记录或聊天记录中删除 |
| 鼠标滚轮 | 翻页 |
| 鼠标悬停 | 选中候选项，并显示实际搜索内容 |
| 标题旁的 `?` | 查看操作说明 |
| Tab | 接受灰色文字补全 |
| Ctrl + Tab | 切换页面或来源筛选 |
| ← / → | 搜索框为空时翻页 |
| PageUp / PageDown | 随时翻页 |
| ↑ / ↓ | 保留 NEI 原有的搜索历史操作 |

Enter 只会搜索当前鼠标悬停的候选项；没有悬停候选项时，会交还给 NEI 处理。

## 配置与扩展

### 配置文件

主配置文件位于：

`config/neiguess/neiguess.cfg`

也可以通过模组列表中的配置界面进行修改。

搜索历史、收藏、点选记录和任务浏览记录保存在：

`config/neiguess/history.json`

### 自定义词库

可以在以下目录添加 JSON 词库：

`config/neiguess/lexicon/`

支持的词库类型：

| 文件类型 | 用途 |
|---|---|
| `mods` | 模组名称别名 |
| `ores` | 矿物词典别名 |
| `oreDisplay` | 矿物词典显示名称 |
| `recommend` | 推荐搜索词 |

修改后执行 `/neiguess reload` 即可重新加载，无需重启游戏。

### 模组集成

其他模组可以通过 IMC 添加自定义词条：

- `addModAlias`
- `addOreAlias`
- `addRecommendWord`

也可以通过 `NEIGuessAPI.registerSource` 注册新的候选来源，自定义来源拥有独立页面和对应的显示逻辑。

内置的收藏、历史、任务等来源也使用同一套 API 实现。

## 与 JEI Guess 相比

NEI Guess 在原版思路上做了一些针对 1.7.10 和 GTNH 环境的改进：

- **更自然的交互**：打开 NEI 时不会自动弹出建议面板，只有点击搜索框或开始输入时才显示；面板显示时也会自动隐藏下方的物品提示。
- **更好的搜索性能**：直接使用 NEI 的物品列表建立索引，包含不同 Meta 的物品变种；索引在 NEI 工作线程中构建，后续输入优先基于上一次搜索结果筛选，避免反复扫描整个物品列表。
- **更准确的纠错**：只比较名称长度相近的候选词，并缓存搜索结果探测，减少不必要的计算。
- **更可靠的任务推荐**：跳过已经完成的子任务，并正确处理 BetterQuesting 数据库同步期间的状态。
- **可扩展的词库**：支持 JSON 配置、IMC 和 Java API，不需要修改模组本身就能添加别名和推荐来源。
- **数据安全**：搜索历史使用原子写入，降低意外中断导致数据损坏的风险；CSV 导出带 BOM，可以直接使用 Excel 打开。
- **中英文支持**：界面和配置均提供中文、英文版本。

## 命令

以下命令均为客户端命令，不会发送到服务器。

| 命令 | 说明 |
|---|---|
| `/neiguess quest` | 查看最近浏览的任务及其所需物品 |
| `/neiguess show <modid:name[@meta]>` | 打开指定物品的合成表 |
| `/neiguess fav <词>` | 收藏或取消收藏搜索词 |
| `/neiguess ban <词>` | 屏蔽指定候选词 |
| `/neiguess unban <词\|all>` | 恢复指定候选词或全部候选词 |
| `/neiguess stats` | 查看模组统计信息 |
| `/neiguess export` | 导出搜索历史为 CSV |
| `/neiguess reload` | 重新加载自定义词库 |

导出的文件保存在：

`config/neiguess/export-<时间>.csv`

## 兼容性

| 项目 | 支持版本 |
|---|---|
| Minecraft | 1.7.10 |
| 加载器 | Forge 10.13.4 |
| NEI | NotEnoughItems（GTNH 2.8+） |
| 必需依赖 | GTNHLib |
| 可选依赖 | BetterQuesting、NotEnoughCharacters |

这是一个纯客户端模组，服务器无需安装。

BetterQuesting 和 NotEnoughCharacters 均为可选依赖。未安装对应模组，或其内部数据结构发生变化时，对应功能会自动跳过，不影响其他功能。

## 构建

需要配置好对应的 Java 和 Gradle 开发环境。

```bash
./gradlew build
```

构建产物位于：

```text
build/libs/neiguess-<版本>.jar
```
